# ADR-0005: 数据库只存真实路径，展示路径只在渲染层生成

- 状态：已采纳（2026-11-19）
- 相关：实现文档 §3.3 / §4.2

## 背景

首版 CLI 把 `paths::display()`（含 `~` 缩写与正斜杠）写入 `client.global_paths` 等列，
随后扫描器把它们当文件系统路径使用，`~` 不被展开 → 所有根都被判为"不存在"，真机扫描结果为 0。

## 决策

1. 所有持久化路径（`client.*_paths`、`target.path`、`detected.path`、`detected.real_path`）必须是
   真实、绝对或项目相对的原始路径；
2. `display()` 只允许出现在渲染层（CLI 输出、GUI DTO），不得回灌数据库；
3. 需要相对展示时由 UI 现算，不存储。

## 后果

- 路径身份不再依赖语言/家目录，库可以在机器间搬迁（配合锁文件）；
- 新增一处约束需要 code review 把关，后续可加编译期包装类型（`StoredPath`）强制。
