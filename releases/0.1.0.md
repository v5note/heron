## 中文说明

**Heron（苍鹭）v0.1.0** 是首个正式可分发版本，支持 **macOS（Apple Silicon）** 与 **Windows（x64）** 双平台桌面应用及统一命令行工具（CLI）。

Heron 将散落在各个 AI 编程工具与项目目录中的 Agent Skill（`SKILL.md`）收拢为单一受版本管理的真实源（`~/.heron/skills/`），按需单向投影到不同客户端与项目落点，并基于 `git merge-tree` 实现保留本地定制的三方合并升级。

### 核心特性

- **收拢与去重（Scan & Adopt）**
  - 多线程只读扫描磁盘，支持流式进度反馈与安全取消；自动解析 `SKILL.md` Frontmatter 并计算 Blake3 内容指纹
  - 备份后安全收拢至统一存储区，相同内容自动去重，原位置替换为受管链接，同时支持就地绑定（`live-bind`）与保留第三方安装器上游信息
- **单向投影与 4 种模式（Project）**
  - 支持 `symlink`（macOS / Linux 默认）、`junction`（Windows 免管理员提权默认）、`pointer`（代理 `SKILL.md`）与 `copy`（含漂移检测 `E_DRIFTED`）
  - 支持逐客户端、逐项目落点精准开关与批量投影，内置冲突与漂移保护，拒绝静默覆盖
- **13 款 AI 客户端动态感知**
  - 内置 Claude Code、Codex、Cursor、Trae、Trae CN、Qoder、WorkBuddy、Cline、GitHub Copilot、Grok Build、Antigravity、opencode、`.agents` 能力表
  - 非侵入式探测本机安装状态，未检测到时仅灰显标注，不修改或删除用户配置
- **Per-Skill Git 仓库与三方合并升级（Upgrade）**
  - 每个纳管 Skill 均为独立 Git 仓库（`main` / `upstream` 分支与 `v<version>` 版本标签）
  - 升级通过隔离树 `git merge-tree` 完成三方合并：无重叠自动合并、冲突时提供逐文件可视化合并界面（工作区保持干净），亦支持覆盖模式与一键回滚（`heron rollback`）
- **6 大内置市场与收藏夹（Sources & Favourites）**
  - 统一对接 `skills.sh`、`ClawHub`（应用内直接检索）以及 `Qoder`、`SkillHub`、`ModelScope`、`SkillsMP`（引导安装 / 粘贴链接解析）
  - 支持单 Skill、Monorepo 子目录、blob 链接、SSH 与本地 Git 仓库安装，支持收藏夹管理与安装计划预览
- **安全治理、体检与团队协同**
  - `heron verify` / 健康体检（Doctor）严格诊断生效状态、坏链、压制与漂移；支持回收站安全删除与失效 Skill 清理
  - `heron.lock` 锁文件（`export` / `diff` / `apply`），无绝对路径，一键复现团队一致的 Skill 环境
- **桌面应用与 CLI 同构**
  - 基于 Rust + Tauri 2 + Vue 3 构建，GUI 与 `heron` CLI 共用 `heron-service` 核心逻辑
  - 内置 4 套主题（默认 / 暮色 / 林墨 / 晚晴）、自动/浅色/深色模式、中英文国际化、全局 `⌘K` / `Ctrl+K` 快捷搜索、原生菜单栏、系统托盘、开机自启与单实例保护

#### 首次打开说明

当前发布包采用 Tauri 内置 **minisign 更新签名**，未购买付费系统级代码签名证书。首次启动时请手动放行：

- **macOS**：右键点击应用 →「打开」（或在「系统设置 → 隐私与安全性」中点击「仍要打开」）

## English Release Notes

**Heron v0.1.0** is the first distributable release, shipping desktop installers for **macOS (Apple Silicon)** and **Windows (x64)** alongside the unified `heron` CLI.

Heron gathers Agent Skills (`SKILL.md` bundles) scattered across AI coding tools and project repositories into a single versioned source of truth (`~/.heron/skills/`), projects them unidirectionally to selected clients and projects, and upgrades them via `git merge-tree` three-way merges while preserving local customizations.

### Highlights

- **Scan & Adopt**
  - Multi-threaded, read-only disk scanner with streaming progress and cooperative cancellation; parses `SKILL.md` frontmatter and computes Blake3 content hashes
  - Safely backs up and adopts skills into the central store with automatic content deduplication, managed link replacement, in-place `live-bind` support, and upstream metadata preservation
- **Unidirectional Projection (4 Modes)**
  - Supports `symlink` (default on macOS/Linux), `junction` (default on Windows without requiring elevation), `pointer` (proxy `SKILL.md`), and `copy` (with `E_DRIFTED` drift detection)
  - Per-client and per-project projection toggles, batch projection, and strict conflict/drift protection that refuses silent overwrites
- **Dynamic Detection for 13 AI Clients**
  - Built-in capability definitions for Claude Code, Codex, Cursor, Trae, Trae CN, Qoder, WorkBuddy, Cline, GitHub Copilot, Grok Build, Antigravity, opencode, and `.agents`
  - Non-invasive presence probing; undetected clients are clearly marked without ever altering or deleting user configurations
- **Per-Skill Git Repositories & Three-Way Merge Upgrades**
  - Every managed skill lives in its own Git repository (`main` / `upstream` branches and `v<version>` tags)
  - Upgrades run in-memory `git merge-tree` three-way merges: clean auto-merge when non-overlapping, side-by-side per-file conflict resolution without dirtying the working tree, optional overwrite mode, and one-click rollback (`heron rollback`)
- **6 Built-in Marketplaces & Favourites**
  - Unified access to `skills.sh` and `ClawHub` (indexed in-app search) plus `Qoder`, `SkillHub`, `ModelScope`, and `SkillsMP` (guided / URL install)
  - Install from single-skill repos, monorepo subpaths, blob URLs, SSH remotes, or local repos; bookmark entries in My Favourites with dry-run install previews
- **Diagnostics, Safe Deletion & Team Lockfiles**
  - `heron verify` and read-only Health (Doctor) diagnostics audit live visibility, broken links, shadowing, and drift; includes recycle-bin safe deletion and stale skill cleanup
  - Portable `heron.lock` (`export` / `diff` / `apply`) with zero absolute paths for reproducible team setups
- **Isomorphic Desktop App & CLI**
  - Built with Rust + Tauri 2 + Vue 3; GUI and `heron` CLI share the exact same `heron-service` core
  - Ships with 4 themes (Default, Dusk, Forest Ink, Evening Clear), Auto/Light/Dark modes, Chinese & English i18n, global `⌘K` / `Ctrl+K` command palette, native menu bar, system tray, autostart, and single-instance guard

#### First-Launch Note

Release binaries use Tauri's built-in **minisign update signing** without paid OS code-signing certificates. On first launch:

- **macOS**: Right-click the app → **Open** (or allow it in *System Settings → Privacy & Security → Open Anyway*)
- **Windows**: Click **More info** → **Run anyway** in the SmartScreen prompt

All subsequent in-app updates (*Settings → App Updates*) are cryptographically verified against the embedded minisign public key; tampered or unsigned payloads are rejected. See [docs/SIGNING.md](https://github.com/v5note/heron/blob/main/docs/SIGNING.md) for details.
