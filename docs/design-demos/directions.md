# 六张方向卡（三套逻辑 × 各两候选）

题材约束：Heron 已有设计系统（羊皮纸双主题、Manrope+EB Garamond+JetBrains Mono、212px rail + 48px topbar）。
品牌=产品自身，六版全部在同一 token 系统内，差异落在骨架与信息组织（design-context 优先级 1：用户自己的 design system）。

## 1 · 最佳设计师｜Dieter Rams（ Braun 6061 式「操作面即仪器」）
- 逻辑与来源：假如预算无上限，为「精密运维工作台」做设计的最合适人选——Rams 的功能等级制。
- 借的是什么：操作面就是仪器本身；一个层级只有一个主角操作；数字全部 tabular；颜色只在状态出现；间距按固定模数收拢，控件对齐到同一基线网格。
- 主角素材：界面自身（真实数据 + 真实组件词汇），扫描按钮变成唯一的「仪器」。
- 骨架：概览 = 左「决定队列」右「系统读数」两栏，读数区做成仪器面板（大 tabular 数字 + 状态点阵）；扫描进度只存在于按钮变形 + 顶栏轨，无第三处。
- 胆量花在哪：按钮原地变成带刻度的进度仪器（6 格 root 刻度点亮）。
- form 来自内容的哪里：扫描是「按 root 数确定推进」的操作，刻度格直接来自 root_total=6 这个真实结构。

## 2 · 最佳设计师｜原研哉（「空」：留白即进度）
- 逻辑与来源：原研哉的素材本身说话、极少的字。
- 借的是什么：一屏一个焦点；文字退为注解；进度不是条，是「页面在呼吸」——留白的节奏变化传达活动。
- 主角素材：界面负空间；扫描时唯一动的是顶栏一根细线。
- 骨架：概览单栏纵向流：此刻 → 需要决定（最多 3 条）→ 系统读数（极小注脚行）；扫描态 = 细线 + 一行小字，其余页面照常。
- 胆量花在哪：把「52 个新发现」做成页面中央一行慢慢浮现的衬线短句。
- form 来自内容的哪里：Heron「只报真有把握的事实」的性格 = 少即是诚实。

## 3 · 现实参照｜Linear（同媒介：macOS 桌面应用，后台任务 UX）
- 逻辑与来源：Linear 的 sync/离线任务处理（未截参考板——离线环境无法访问其官网截图；卡上诚实标注「未亲眼看到」，凭对其交互系统的公开描述拆规则）。
- 借的是什么：任务 pill 常驻不挡内容；数据实时流入列表（diff 式更新）；chrome 极安静、内容极活跃；键盘优先；计数在侧栏即时跳动。
- 主角素材：流入的发现卡片流 + 扫描 pill。
- 骨架：概览 = 双栏工作台（左决定队列带行内操作，右「扫描活动」实时流：每个 root 一行，发现即加行）；扫描中顶栏轨 + pill + 概览活动区三处同源。
- 胆量花在哪：概览右栏就是扫描的实时日志流（root 行 + 发现计数滚动）。
- form 来自内容的哪里：扫描本来就是「逐 root 出结果」的过程，日志流是这个过程的直接映射。

## 4 · 现实参照｜Things 3（同媒介：macOS 桌面应用，列表的镇静感）
- 逻辑与来源：Cultured Code Things 3 的同步进度与「今天」列表（未截参考板，凭公开界面拆规则，诚实标注）。
- 借的是什么：标题即锚点；列表行是主要信息原子，行内完成操作；状态靠位置与字重，不靠颜色轰炸；进度指示小到几乎看不见但永远在场。
- 主角素材：一列列真实的决定行（每条自带跳转与计数）。
- 骨架：概览废除卡片网格，改「一本账」：按紧急度分组的连续列表（坏链区/决定区/读数区），读数收进列表末尾一行内联文字；扫描态 = 列表顶部一条 1px 分隔线下的细进度句。
- 胆量花在哪：整页只有一种容器（行），层级全部由缩进与字重表达。
- form 来自内容的哪里：概览的问题就是「接下来做什么」——列表是唯一诚实的形状。

## 5 · 秒数轮盘·web #6｜巨型字黑白高对比（Bold Big-Type Editorial）
- 逻辑与来源：design-styles.md 网页分区第 6 条（样张 assets/style-specimens/web/06-bold-big-type.jpg；秒数 45 → 45%20+1=6…编号 6）。
- 借的是什么：极端字号反差（巨号数字压小标签）、负空间博弈、左右对位；点缀色克制。
- 主角素材：数据即图像——52、6、1 三个真实数字放大成页面主角。
- 骨架：概览首屏 = 一行三枚巨型 tabular 数字（待决定/落点/纳管）+ 各自一行注解；下方才是决定队列；扫描态 = 巨号数字变成实时发现计数（0→52 滚动）。
- 胆量花在哪：把统计数字放大到 96px 级，页面像一张数据海报。
- form 来自内容的哪里：概览的核心事实就是三个数，数字本来就该最大。

## 6 · 秒数轮盘·east #10｜服部一成玩味错位（Hattori Playful Offset）
- 逻辑与来源：design-styles.md 中文与东亚分区第 10 条（样张 assets/style-specimens/east/10-hattori-playful-offset.jpg；秒数 45 → 45%12+1=10）。
- 借的是什么：**玩味集中在一处不蔓延**；条纹替网点；信息栏老老实实。降级说明：手写标题与油墨叠印不做，只借「一处错版惊喜 + 其余全部规矩」。
- 主角素材：扫描中的「扫」字巨纹章（条纹填充、双层错位）。
- 骨架：概览规矩双栏 + 扫描态时页面右半浮现一枚条纹「扫」字印章动画，发现卡片像印刷一样逐张「落」进流（轻微错位沉降）；信息区完全不动。
- 胆量花在哪：扫描中的巨型错版印章 + 卡片沉降印刷感。
- form 来自内容的哪里：Heron 的「苍鹭/印章」品牌母题（rail 上那枚 seal）放大成扫描时刻的主角。
