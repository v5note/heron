# 来源与市场 · 重设计 — spec + 方向卡

## 顾问式重述（本质需求）

Heron 是本地 Skill 管理器（Tauri2 + Vue3，暖纸主题）。当前「来源与市场」页有三个硬伤：

1. **搜完装不了**：skills.sh / ClawHub 已能算出 git 安装计划（`InstallPlan::Git{url,subpath}`），但 UI 只给「在浏览器打开」，等于市场没意义。
2. **来源能力过时**：skillhub.cn 与 modelscope.cn/skills 实际都「可搜索 + 可安装」（已核实），却被归到「仅浏览器」。
3. **没有收藏**：用户看到好的开源 Skill（github/gitee）无法沉淀，每次重新找。

重设计要交付一个界面，同时承载：① 可搜索市场 → 一键安装；② 仅浏览市场 → 打开深链 + 粘贴安装；③ **收藏夹**（名称/地址/描述，一键安装，可手动添加 github/gitee 条目）；④ 粘贴地址安装（保留）。

受众：本机开发者。基调：克制、专业、像原生工具，不喧哗。三版都画在 Heron 真实外壳里（左侧栏 + 顶栏「扫描本机/校验」+ 暖纸浅色主题），差异落在**信息架构/骨架**，不是配色。

## 三套逻辑各两候选（六张），挑三做完整版

### 完整版 A — 双栏工作台（master-detail）
- **逻辑与来源**：现实参照 · Linear / Things 式主从工作台；借的是「左窄列表选上下文、右宽区放内容」的密度关系。
- **借的是什么**：左栏来源列表竖向、带能力点 + 健康点 + 计数；右栏随选中来源切换内容（市场搜索 / 收藏 / 粘贴）。
- **主角素材**：真实搜索结果行 + 收藏卡，纯排版，无装饰图。
- **骨架**：`[来源列表 | 内容区]` 两栏；内容区顶部 segmented「市场结果 / 我的收藏」。
- **胆量花在哪**：把「来源」做成可勾选启停 + 健康探针的活列表，而非一排静态 tab。
- **form 来自内容**：管理器本质是「选一个来源 → 看它的东西」，主从结构就是这件事的形状。

### 完整版 B — 统一搜索流（跨市场一次搜）
- **逻辑与来源**：秒数轮盘 → 检索式聚合页（Google Scholar / Algolia 聚合结果）；直接回应用户「搜完就能装、跨市场」的诉求。
- **借的是什么**：一个搜索框查所有启用来源，结果按来源分组、带来源徽标，每行右侧「安装」；收藏是并列的第二个 tab。
- **主角素材**：分组结果 feed + 来源徽标 chip。
- **骨架**：单搜索框置顶 → 分组结果流（skills.sh / ClawHub / SkillHub / ModelScope 各一段）；顶部 segmented「全部来源 / 我的收藏」。
- **胆量花在哪**：取消「先选市场」这一步，一次搜全网，直击「市场没意义」的痛点。
- **form 来自内容**：用户抱怨的是「搜完装不了」，所以把搜索→安装做成一条不断流。

### 完整版 C — 卡片市场 + 收藏抽屉
- **逻辑与来源**：最佳设计师 · 信息密度克制的工具型设计（Base44 / Raycast 商店）；借卡片网格 + 侧滑详情。
- **借的是什么**：来源做成富卡片（能力/健康/skill 数/启停开关）网格；点卡片在页内展开搜索+安装面板；收藏是独立视图，添加收藏走**侧滑抽屉表单**（用户偏好 L1：复杂编辑表单用抽屉）。
- **主角素材**：来源卡片 + 收藏卡网格 + 抽屉表单。
- **骨架**：顶部 segmented「市场 / 收藏」；市场=卡片网格+选中卡片下方内联面板；收藏=卡网格+右上「+ 添加收藏」开抽屉。
- **胆量花在哪**：收藏的新增/编辑用抽屉承载名称/地址/描述三字段 + 校验 + 一键安装。
- **form 来自内容**：来源是「可逛的货架」、收藏是「我的清单」，两种密度用卡片+抽屉分别承载。

### 备选（未做完整版，缩略图里给用户看）
- **D**：标签页式（市场/收藏/粘贴 三 tab 平铺），最接近现状的渐进改良。
- **E**：终端/命令行隐喻（`heron install …`），⚠️ 属万能隐喻，最多保留概念，不优先。
- **F**：单栏瀑布（来源折叠手风琴 + 结果内联展开），移动感强但桌面浪费宽度。

## 硬约束
- 全部暖纸浅色主题（截图即此），至少跳出近黑底 Manrope 账本（暖纸已天然跳出）。
- 正文≥14px、标签≥12px、对比度≥4.5:1；不编造数据，未知留诚实占位。
- 复用 Heron 设计语言：圆角 10px、hairline 边框、chip 状态点、mono 路径、`.btn/.card/.table/.drawer`。
- 三版同内容（同一批真实来源与示例结果），只换 IA/骨架。
