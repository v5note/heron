# Heron Tauri 图标（原剪影 + 白底圆角）

本版直接使用原始透明剪影，只在其下方合成白色圆角底，没有重绘、平移或裁切苍鹭轮廓。

- `icon-master.png`：原图尺寸 1254 × 1254，RGBA。
- `icon.icns`：macOS 图标。
- `icon.ico`：Windows 多尺寸图标。
- `32x32.png`、`128x128.png`、`128x128@2x.png`、`icon.png`：Tauri 常用 PNG 尺寸。
- `16x16.png`、`24x24.png`、`48x48.png`、`64x64.png`、`256x256.png`、`512x512.png`：额外 PNG 尺寸。

`src-tauri/tauri.conf.json` 指向本目录。
