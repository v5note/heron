# Heron 黑底白色剪影图标

白色苍鹭剪影置于黑色圆角底板上，保留橙色喙和黄色眼睛。底图由附件中的透明白色剪影直接合成，没有重绘或裁切鸟形。

- `icon-master.png`：1254 × 1254 RGBA 高分辨率母图。
- `icon.icns`：macOS 应用图标。
- `icon.ico`：Windows 多尺寸图标。
- `32x32.png`、`128x128.png`、`128x128@2x.png`、`icon.png`：Tauri 常用 PNG 尺寸。
- `16x16.png`、`24x24.png`、`48x48.png`、`64x64.png`、`256x256.png`、`512x512.png`：额外 PNG 尺寸。

`src-tauri/tauri.conf.json` 已指向本目录；其他图标版本仍保留在各自目录。
