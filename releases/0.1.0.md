## Heron 0.1.0

首个可分发版本。

**功能**

- 扫描并收拢散落在 Claude Code / Codex / Cursor / opencode / .agents 与项目目录的 Skill
- 一份实体 + 按客户端投影（符号链接 / junction / 复制），冲突与漂移均拒绝覆盖
- 三个客户端属性由能力表驱动，未验证的客户端永不写入
- 从 Git 仓库或五个市场安装，三方合并升级，冲突可逐文件解决
- `heron.lock` 团队复现
- 桌面应用（Tauri 2 + Vue 3）与命令行共用同一套逻辑

**安装**

- macOS：`Heron_0.1.0_aarch64.dmg`
- Windows：`Heron_0.1.0_x64-setup.exe`

首次打开需要手动放行（未做系统级代码签名）：macOS 右键 → 打开；Windows 更多信息 → 仍要运行。
详见 [docs/SIGNING.md](docs/SIGNING.md)。

**更新**

应用内检查更新，更新包经 minisign 签名校验。
